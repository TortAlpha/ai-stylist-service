# SQL tests (product-service)

Run schema/trigger invariant tests against a temporary PostgreSQL database inside `postgres-product`.

## Prerequisites

- Container is running: `docker compose up -d postgres-product`
- Bootstrap SQL is mounted in container: `/docker-entrypoint-initdb.d/init.sql`

## Run

```bash
server/product-service/tests/sql/run_sql_tests.sh
```

Optional env vars:

- `CONTAINER_NAME` (default: `postgres-product`)
- `PGUSER` (default: `postgres`)
- `PGADMIN_DB` (default: `postgres`)
- `TEST_DB` (default: autogenerated `product_db_sqltest_<ts>_<rand>`)

## What is validated

- Root category uniqueness (`parent_id IS NULL` uniqueness by name+gender)
- Category hierarchy guards (gender compatibility, cycle protection)
- Product status transition rules
- `product_details` consistency guards by `product_type` and `size_group`
- Undirected uniqueness in `similar_products`
- `product_history.version` consistency with `product.version`
